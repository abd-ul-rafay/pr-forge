# PR Forge

Small web app for turning **issue context** and **what you changed** into draft **pull request titles and descriptions**. Generation via AI is planned next; today the UI collects your inputs and a length preference (short / medium / long).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Other useful commands: `npm run build`, `npm run lint`.
